# Content Center V2 — тестовый предпросмотр

Это **изолированная демонстрация** интерфейса настоящей ветки V2. Все данные клиентов и материалов вымышлены и живут только в памяти текущей вкладки. Перезагрузка страницы сбрасывает изменения.

- Сайт не обращается к рабочей базе Supabase, не использует код владельца и не может отправить публикации в Instagram/Telegram.
- Используется проверенный V2-код с подменой внешнего клиента Supabase на in-memory mock и запретом внешних соединений.
- Вход выполняется автоматически под фиктивной тестовой сессией; это не тест сервера авторизации.
- Цель: проверить интерфейс ПК/Safari iPhone, переключение клиентов, шесть шагов нового клиента, создание материала и предупреждения о дублях.

**Важное:** Live-контент и публикация не проверяются здесь; для них требуется отдельный тестовый backend и реальное согласование.
